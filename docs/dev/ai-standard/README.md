# AI development standard

28.10.2026 · @ilnar

How agents work in this repository: the task path from clarification to commit, the Claude Code setup (`CLAUDE.md`, hooks, skills, MCP), how we check the agent's work, and which external tools we use. The standard applies to the whole repository: backend, frontend and documentation.

**How to use it**

1. Start with [00-overview.md](00-overview.md): decisions A1–A14 and the map of sections.
2. The [development process](../dev-process.md) gives the steps of the task cycle and the rules for parallel work. This standard tells how agents do these steps and how we check them.
3. The spec format is [05 of the frontend standard](../frontend-standard/05-spec-driven-development.md), with the change from [ADR 0002](../adr/0002-specs-openspec-hybrid.md). This standard replaces group B of the frontend standard (04, 06, 07, 08, 37): [ADR 0006](../adr/0006-ai-standard-project-wide.md).
4. A deviation needs an ADR.
